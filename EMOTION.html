EmotionLens: Sentiment & Emotion Highlighter

Making digital communications more accessible for neurodiverse users

Analyze and understand emotional context in emails, messages, and web content with real-time highlighting

Key Features

Advanced NLP Analysis

Powered by DistilBERT and RoBERTa models for accurate sentiment and emotion detection in real-time.

Visual Highlighting

Color-coded highlighting and emoji cues make emotional context immediately visible and understandable.

Customizable Settings

Adjust sensitivity, filter specific emotions, and personalize highlighting styles to match your needs.

Universal Compatibility

Works across websites, email platforms, and messaging applications for consistent support everywhere.

Contextual Explanations

Hover over highlighted text to see explanations of why content was classified with a specific emotion.

Privacy-First Design

All processing happens locally on your device. No text data is sent to external servers.

Installation Instructions

Chrome/Edge Installation
  1. Download the extension file (.crx)
  2. Open Chrome/Edge and go to Extensions
  3. Enable Developer Mode
  4. Drag and drop the extension file
  5. Confirm installation
Firefox Installation
  1. Download the extension file (.xpi)
  2. Open Firefox and go to Add-ons
  3. Click the gear icon and select "Install Add-on From File"
  4. Select the downloaded file
  5. Confirm installation
The extension works locally on your device and doesn't send any data to external servers.
